# С днем рождения, Соня

Пиксельная вечериночная викторина для **Google TV** (Android TV APK).  
Управление — **пульт ТВ** (D-pad + экранная клавиатура). Гости смотрят на большой экран.

Стилистика: ретро 80-е в сеттинге «робокар / город спасателей» (оригинальные ассеты, без кадров из мультфильмов).

## Что умеет MVP

1. **Лобби гостей** — ввод имён с экранной клавиатуры пульта (минимум 2).
2. Кнопка **ДЕМО ГОСТИ** — быстро подставляет Аня/Боря/Вика для проверки.
2. **Прогресс по буквам** фразы `С ДНЕМ РОЖДЕНИЯ, СОНЯ` (17 букв; стрелка на текущей).
3. **Круг участников** — равноразделенный спиннер; fair-очередь (выбывает до нового круга).
4. **3 демо-уровня**: картинка / видео с паузой / аудио + поле ответа.
5. **Слоты озвучки** — WAV-заглушки на старт, спин, верно/неверно, победа (потом просто заменить файлы).

После трёх демо — экран «демо пройдено»; остальные буквы остаются серыми.

## Структура

```
app/                      Flutter-проект (Android TV + web)
  lib/                    экраны, GameController, круг, тема
  assets/levels/demo.json контент демо-уровней
  assets/audio/voice/     плейсхолдеры озвучки
android/                  LEANBACK_LAUNCHER, landscape
```

## Скачать APK

Готовый release лежит в репозитории (не в `build/` — эта папка в `.gitignore`):

- [`dist/sonya-birthday-release.apk`](dist/sonya-birthday-release.apk)

На GitHub: откройте файл → кнопка **Download** / **View raw**.

## Сборка APK

Нужны Flutter (stable) и Android SDK.

```bash
cd app
flutter pub get
flutter test
flutter build apk --release
```

Готовый файл:

`app/build/app/outputs/flutter-apk/app-release.apk`

### Sideload на Google TV

1. На ТВ: **Настройки → Система → О устройстве** — несколько раз по «Сборка», включить **Для разработчиков**.
2. Включить **Отладка по USB** / **ADB** (или установить через USB-накопитель / Apps Store sideload-утилиту вроде Downloader).
3. С компьютера в одной сети:

```bash
adb connect <IP-телевизора>:5555
adb install -r app/build/app/outputs/flutter-apk/app-release.apk
```

4. Запуск из раздела приложений Google TV (иконка «Соня ДР»).

## Управление пультом

| Действие | Пульт |
|----------|--------|
| Навигация | Стрелки |
| Подтвердить | OK / Select |
| Назад | Back |
| Ввод имени / ответа | Экранная клавиатура |
| Геймпад | Задел под будущие мини-игры (`InputRouter`) |

## Контент уровней

Редактируйте `app/assets/levels/demo.json`:

- `picture_question` — `imageAsset`, вопрос, `acceptedAnswers`
- `video_question` — `videoAsset`, `pauseAtMs`
- `audio_question` — `audioAsset`

Озвучка: положите файлы в `assets/audio/voice/` и укажите пути в `voiceLines`.

## Разработка без ТВ

```bash
cd app
flutter run -d chrome   # удобно для UI
# или эмулятор Android TV в Android Studio
```
